# Animations Standard

## Purpose

Motion must clarify workflow state, feedback, and continuity without distracting from professional work.

## Requirements

- Use subtle, fast, consistent timing.
- Animate state changes only when motion improves comprehension.
- Provide reduced-motion alternatives.
- Keep critical workflow information visible without relying on animation.
- Avoid decorative motion that adds render cost or visual noise.

## Review Gate

Motion Designer and Performance Engineer must review animation-heavy changes.
