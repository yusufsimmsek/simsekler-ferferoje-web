# ArchiFlow Premium Visual Assets

These assets are generated raster visuals used as the primary module hero artwork for ArchiFlow's product experience.

## Provenance

- Created for the Visual Asset Director pass on 2026-07-03.
- Generated as one original architectural visual asset sheet, then cropped into module-specific hero covers.
- Purpose: replace SVG placeholder hero scenes with production-ready raster visuals that make every module feel like a premium architectural workspace.
- These files are decorative product visuals and do not represent real client project data.

## Categorized Asset Library

- The complete 45-asset library brief is tracked in `docs/ARCHIFLOW_VISUAL_ASSET_GENERATION_BRIEF.md`.
- Generated assets for that library must live in the category folders under this directory.
- `asset-manifest.json` is the machine-readable map from product usage to stable public asset paths.
- Existing flat assets in this folder are retained for compatibility and must not be overwritten by new generation passes.

## Usage Rule

Use these images as the primary visual layer for module hero experiences. Simple SVG drawings may remain only as secondary overlays, motion accents, or supporting diagrams.
