# ArchiFlow Visual Asset Generation Brief

This document is the canonical prompt source for the complete ArchiFlow visual asset library.

ArchiFlow is a premium AI-powered architectural operating system for Turkish urban transformation workflows. It helps architects manage project intake, parcel and zoning analysis, depth/Hmax checks, old plan review, quantity extraction, core selection, apartment mix, share allocation, and proposal/report generation.

The goal is to create a coherent professional visual system, not isolated images.

## Global Style

All visuals must feel like they belong to the same product universe.

Visual direction:

- premium architectural software
- Apple / Linear / Figma / Autodesk level polish
- modern Turkish urban transformation context
- calm, elegant, technical
- high-end architectural visualization
- glass, concrete, steel, soft light
- subtle blueprint overlays
- transparent analysis layers
- refined shadows
- precise geometry
- no generic SaaS illustration
- no placeholder SVG
- no cartoon style
- no cheap 3D icon look

Color palette:

- deep navy
- architectural white
- soft blue-gray
- electric violet accent
- glass cyan
- restrained warm architectural light
- no oversaturated neon

Rendering style:

- cinematic but clean
- premium product UI asset quality
- semi-isometric where useful
- realistic materials
- transparent glass overlays
- technical drawing layers
- calm negative space for UI

Global negative prompt:

cheap dashboard illustration, cartoon, flat vector, childish icon, generic stock image, messy composition, unreadable text, fake UI text, low quality, distorted building, over-saturated neon, cyberpunk city, people in foreground, watermark, logo, random letters, random numbers, blurry, noisy, cluttered, amateur render, placeholder graphic

## File Naming And Placement Rules

All generated assets must be saved with clean, consistent, production-ready filenames.

Use this naming format:

`archiflow-[asset-number]-[usage-area]-[short-description].[ext]`

Examples:

`archiflow-01-dashboard-hero-building.webp`  
`archiflow-03-process-parcel-zoning.webp`  
`archiflow-21-document-pdf-report-preview.webp`

Use lowercase letters only.  
Use hyphens instead of spaces.  
Do not use Turkish characters in filenames.  
Do not use random UUIDs.  
Do not use temporary names like image1, final, export, new, test, copy.

Preferred output format:

- `.webp` for large UI visuals
- `.png` for transparent icons or objects
- `.jpg` only if WebP is not available

Recommended folder:

`/public/visual-assets/archiflow/`

If categories are supported, use this structure:

```txt
/public/visual-assets/archiflow/
  dashboard/
  process-cards/
  workflow/
  projects/
  ai/
  empty-states/
  documents/
  maps/
  modules/
  icons/
  backgrounds/
  avatars/
```
