# Design Review Template

## Scope

Use for any user-facing screen, component, visual-system, or motion change.

## Required Reviewers

- Principal Product Designer
- Design Critic for high-visibility screens
- Motion Designer when motion changes
- UX Researcher for workflow or comprehension changes
- Frontend Engineer for implementation feasibility

## Checklist

- Premium architectural-office feel
- Clear hierarchy and next action
- Consistent typography, spacing, colors, and states
- No generic template appearance
- Responsive layout without overlap or overflow
- Accessible focus, labels, contrast, and reduced motion

## Output

```md
Design verdict:
Blocking issues:
Recommended refinements:
Verification needed:
```
