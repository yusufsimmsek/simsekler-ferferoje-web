# Architecture Review Template

## Scope

Use for domain, API, persistence, AI pipeline, state boundary, and integration changes.

## Required Reviewers

- Senior Architect
- Backend Engineer when APIs/storage are touched
- Frontend Engineer when client state is touched
- AI Engineer when automation or generated outputs are touched
- Security Engineer for trust boundaries
- Knowledge Guardian for documented decisions

## Checklist

- Explicit domain model and contracts
- Safe ownership and trust boundaries
- Clear failure behavior
- Documentation consistency
- Testable implementation boundary

## Output

```md
Architecture verdict:
Affected contracts:
Blocking risks:
Required tests:
Documentation updates:
```
